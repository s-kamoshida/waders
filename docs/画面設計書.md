Waders の画面の構成・レイアウト・操作と、画面に表示する文言を定める。見た目の参考は [mock/index.html](mock/index.html)（モック）。実装（`src/client/`）と常に一致させる。

## 2. 共通

- PC・スマートフォン・タブレットのブラウザで、すべての機能を使える。横幅 600px 以下ではスマートフォン向けの配置にする
  - 横幅 600px 以下とタッチ操作の端末では、入力欄の文字を 16px にする（iOS Safari がタップ時に画面を拡大しないようにするため。指での拡大は禁止しない）（#16）。画像の貼り付け欄も同じ（#47）
  - 年月・日付の入力欄は標準の見た目を外し、入力欄の幅に収める（iOS Safari ではみ出すため）（#16）
- モーダルを開いている間は、背景のページをスクロールさせない（#16）。一覧の領域（下記）のスクロールも止め、閉じたら開く前の位置のまま表示する（#21）
- 画面の最上部にアプリ名「Waders」と、「リスト」（SCR-01）・「アーカイブ」（SCR-04）のタブのヘッダーを固定表示する。開いたときは「リスト」を表示する
- ページ自体はスクロールさせない。ヘッダーより下（ツールバーを含む SCR-01・SCR-04・SCR-08）を、画面の高さに収めた「一覧の領域」としてスクロールさせる（#21）
  - iOS Safari は入力欄にフォーカスしたとき、キーボードに隠れないようにページを自動でスクロールし、`overflow: hidden` では止まらない。ページの高さを画面に収めて動かせる量をなくし、モーダルの入力欄にフォーカスしても背景の一覧が動かないようにする
  - リストとアーカイブは同じ一覧の領域を使う（タブを切り替えても位置は別々に覚えない）
  - キーボード（PageDown・Space・矢印）で一覧をスクロールできるよう、リスト・アーカイブを表示したときやモーダルを閉じたときに、どこにもフォーカスがなければ一覧の領域にフォーカスを置く。入力欄・タブなど、ほかの要素にあるフォーカスは奪わない。モーダルを開いている間は、一覧の領域（モーダルの後ろ）にフォーカスを置かない。一覧の領域は Tab キーでは止まらず、フォーカスの枠線も出さない（PR #29 のレビュー）
- ヘッダーの右端に「カテゴリーの管理」のボタン（タグの絵）を置き、SCR-07 を開く。定義のファイルに誤りがあっても押せる（#10）
- 開いたときに延期の確認を待っている商品があれば、SCR-06 を表示する
- 開いたときに認証の状態を確かめる（#11）。確かめるまでは、ヘッダーのアプリ名だけを表示し、商品を読み込まない
  - 認証が有効で、ログインしていなければ SCR-08 を表示する（どの URL を開いても）。タブ・「カテゴリーの管理」・「ログアウト」は表示しない
  - 認証が有効でログインしていれば、ヘッダーの右端（「カテゴリーの管理」の右）に「ログアウト」（扉から出る矢印の絵と文字。横幅 600px 以下では絵だけにし、文字は読み上げ用に残す）を置く。押すとログアウトして SCR-08（ログイン）を表示する。失敗したら MSG-E-011 を表示する
  - 使っている間に API がログインを求めた（ログインの期限切れなど）場合は、開いているモーダルを閉じて SCR-08（ログイン）を表示する
  - 認証の状態を取得できない場合は MSG-E-009 を表示し、一覧を表示しない
- 日付・月は日本時間で判定する
- スタイルは CSS のクラスで指定する（CSP によりインラインのスタイルは使えない）

## 3. SCR-01 商品の一覧

### 3.1 構成

```
┌ Waders [リスト|アーカイブ]              [🏷] ┐  ← ヘッダー（右端はカテゴリーの管理）
│ [カテゴリー: すべて▾] [暦年|年度]        (＋) │  ← ツールバー
│ ▼ 2026年 5個（合計 100,680円見込）            │  ← 年の見出し
│ ──────────────────────────────────────────── │
│   ▼ 2026/11 3個（合計 77,580円見込）      (＋) │  ← 月の見出し（右端に追加ボタン）
│     [カード][カード][カード][カード]          │  ← 列数は横幅に合わせる
│   ▼ 2027/01 0個（合計 0円見込）           (＋) │
│     商品はありません                          │
└──────────────────────────────────────────────┘
```

### 3.2 表示

- 年・月のグループで表示し、見出しを押すと折りたたみ・展開する（開くたびにすべて展開した状態にする）
  - 年のまとめ方は「暦年」（1月〜12月、表記「2026年」）と「年度」（4月〜翌3月、開始年で表記「FY26」）を切り替える。切り替えはブラウザに保存し、次に開いたときも使う
  - 月の表記は「2026/11」
- 見出しに、個数と合計金額の見込みを「3個（合計 44,000円見込）」と表示する
  - 未購入の商品は含めない
  - 合計は金額・送料・手数料・交通費（見込）・その他費用の合計。金額が未入力の商品は個数だけに含める（費用も含めない）（#26。BR-25）
- 発売月が当月以降の商品だけを表示する。当月より前の商品は SCR-04 に表示する（#9）
- 表示する月は、当月から登録されている商品の最も遅い発売月まで。0 件の月も表示し「商品はありません」と表示する
- 同じ月の中は、購入済 → 予約済 → 予約済（キャンセル可）→ 検討中 → 未購入の順。同じステータスの中は登録順
- 横幅が 600px より広い場合は、カードを横に並べ、列数は横幅に合わせる（カードの幅 180px 以上）
- 横幅 600px 以下（スマートフォン）では、商品を 1 行に 1 件のリスト形式で表示する（3.3）。切り替えは画面の幅で自動で行い、切り替えの操作は置かない。端末の向きを変えるなどで幅が変わったら、開き直さなくても表示の形式を切り替える（#15）

### 3.3 商品のカード

| 部分 | 内容 |
| --- | --- |
| 画像 | 付けた画像（なければ購入先のページから取ったカード画像。#42）を、切らずに枠（横 4:縦 3）の中に収めて表示する（余ったところは枠の背景の色）。画像がない・読み込めなかった場合は共通のアイコン（#41） |
| ステータス | 画像の左上に表示（検討中・予約済・予約済（キャンセル可）・購入済・未購入） |
| メーカー | 入力がある場合だけ、商品名の上に小さく薄い文字で 1 行（長い場合は省略）（#18） |
| 商品名 | 3 行まで。検討中で受注期限まで 0〜7 日の場合は先頭に「⚠️ 」を付ける |
| 場所 | 入力がある場合だけ、商品名の下に小さく薄い文字で 1 行（長い場合は省略）（#26） |
| 金額・送料 | 「24,200円 送料 800円」。送料が未入力・0 円は「送料無料」。金額が未入力は「金額未入力」（送料は表示しない）。「送料無料」は、送料が有効なカテゴリー（未設定・定義にないカテゴリー・定義を読めない場合を含む）の商品だけ。送料が保存されていれば常に「送料 800円」（#27） |
| 費用 | 手数料・交通費（見込）・その他費用のうち値があるものを、金額の行の下に「手数料 330円」「交通費（見込） 2,000円」「ドリンク代 600円」と小さく並べる（その他費用はカテゴリーの名前。BR-26）。金額が未入力でも表示する（#26） |
| 開催 | 開催日時と終了日時の両方がある場合だけ、「開催 11/20 18:00〜21:00」（日本時間。BR-28）。長い場合は省略（PR #30） |
| 備考の印 | 備考がある場合だけ、金額の行の右端に 📝（読み上げは「備考あり」）。本文は表示しない（#18） |
| 受注期限 | 検討中の場合だけ「受注期限 11/20」。⚠️ の対象は赤字 |
| 購入先 | URL のドメインをリンクとして表示し、新しいタブで開く。カードの下端にそろえる（#16） |

横幅 600px 以下のリスト形式（#15）では、同じ項目・同じ表示の規則（ステータスの色・未購入の見せ方・⚠️・送料無料・📝）を、1 行に次のように並べる。操作（押すと SCR-02、購入先は新しいタブ、長押しで掴んで発売月を移動）もカードと同じ。

```
┌─────────────────────────────────────────┐
│▌[🎁] [検討中]                            │  ← 左の線と背景はステータスの色
│▌     メーカーA                           │  ← メーカー（1 行。長い場合は省略）
│▌     ⚠️ 商品名（2 行まで）               │
│▌     24,200円 送料 800円 📝              │
│▌     受注期限 11/20                      │
│▌     開催 約3時間                        │  ← 開催日時と終了日時の両方がある場合（PR #30）
│▌                        shop.example.jp │  ← 購入先は行の下端の右
└─────────────────────────────────────────┘
```

| 部分 | リスト形式での内容 |
| --- | --- |
| 画像 | 行の左端に、付けた画像（切らずに収める）か共通のアイコンを小さく（40px 角）表示する（#41） |
| ステータス | アイコンの右の上段に表示する（画像には重ねない） |
| 商品名 | 2 行まで（カードは 3 行まで） |
| 開催 | 開催日時と終了日時の代わりに、開催期間を「開催 約3時間」「開催 約1.5日」と表示する（場所が限られるため。BR-28。PR #30） |
| 購入先 | アイコンの分を空けて、行の下端の右にそろえる |
| 掴んでいる間 | 影と透明度で浮いた見た目にする。行は横幅いっぱいのため、カードと違って拡大はしない（画面の横にはみ出さないようにするため） |

ステータスの色（モックの配色）:

| ステータス | 背景 | 左の線 | 備考 |
| --- | --- | --- | --- |
| 検討中 | 黄 | 黄 | |
| 予約済 | 白 | グレー | |
| 予約済（キャンセル可） | 青 | 青 | |
| 購入済 | グレー | グレー | 文字を薄くする |
| 未購入 | 白 | 赤 | 枠を赤い破線にし、画像を薄くする（購入済のグレーと見分けるため。取り消し線は付けない） |

| 操作 | 結果 |
| --- | --- |
| ＋ボタン | SCR-02 を「追加」で開く（発売月は当月） |
| 月の見出しの＋ボタン | SCR-02 を「追加」で開く（発売月はその月）。月を折りたたんでいても押せる。SCR-04 には置かない（#16） |

| カードをドラッグして月に落とす | 発売月をその月に移動する（3.6） |

### 3.5 カテゴリーの絞り込み（#10）

- ツールバーの左端のボタンに、選んでいるカテゴリーを「カテゴリー: すべて」「カテゴリー: スケールフィギュア、カテゴリー未設定」のように表示する。選んでいる間はボタンを強調する
- 押すとプルダウンを開き、チェックボックスで複数選べる。選択肢は次の順
  1. 定義のカテゴリー（定義のファイルの並び順）
  2. 定義にないカテゴリーの商品があれば「名前（定義にない）」
  3. 「カテゴリー未設定」
  4. 「選択を解除（すべて表示）」のボタン
- 選んだカテゴリーの商品だけを表示し、見出しの個数と合計金額も絞り込んだ商品で数える。表示する月の範囲も絞り込んだ商品で求める
- 選択はブラウザに保存し、SCR-04 でも同じ選択で絞り込む。保存されている選択のうち選択肢にないものは、選んでいないものとする
- プルダウンの外を押す・Esc キーで閉じる
- カテゴリーの定義に誤りがある場合は、ボタンを使えなくし、商品はすべて表示する。ページの上部に MSG-E-006（サーバーの理由と MSG-I-008）を表示する

### 3.6 ドラッグアンドドロップ（#13）

- PC（マウスなどの細かく指せる端末）: カードを掴んで（ブラウザ標準のドラッグ）、月に落とす
- タッチ操作: カードを 0.4 秒長押しすると掴む。その前に 10px 以上動いたらスクロールとして扱い、短く触れた場合は SCR-02 を開く
  - 掴んでいる間はカードを浮いた見た目にし、画面の上部（ヘッダーの行に重ねて中央。ツールバーには重ねない）に「2027/04 に移動」（月の外では「移動先の月まで動かしてください」）を 1 行で表示する（#15）。ページのスクロールは止める
  - 画面の上端・下端から 80px に入ると、一覧の領域（2. 共通）を自動でスクロールする（#21。端の判定は画面の端のまま）
  - 掴んだ後に指を離しても SCR-02 は開かない
- 落とせる場所: 月の並び（0 件の月を含む）と月の見出し（折りたたんだ月を含む）。移動中は落とす先の月を青い点線で囲み、背景を薄い青にする
- 同じ月に落とした場合は何もしない。SCR-04（アーカイブ）ではドラッグできない
- 移動したら、画面の下端に知らせ（3.7）を表示し、一覧を読み込み直す

### 3.7 画面の下端の知らせ（#13）

| 項目 | 内容 |
| --- | --- |
| 位置 | 画面の下端の中央に、一覧の上に重ねて固定で表示する（下端から 16px とホームバーの分をあける）。PC は文字に合わせた幅（最大 480px）、横幅 600px 以下は左右 16px の余白で横幅いっぱい |
| 見た目 | 濃い灰色の背景に白い文字、角丸、影。右端に「元に戻す」の文字のボタン（明るい青）。失敗は赤い背景 |
| 時間 | 8 秒で消える。出るとき・消えるときは 0.2 秒で薄くなる・濃くなる。マウスを重ねても止めない |
| 数 | 1 つだけ。新しい知らせが出たら置き換える（「元に戻す」は最後の移動だけが対象） |
| ほかの操作 | 表示している間に、追加・編集のモーダルを開く（＋・月の見出しの＋・カードを押す）、年のまとめ方や絞り込みを変える、タブを切り替えるといったほかの操作を始めたら、すぐに閉じる（「元に戻す」も使えなくなる） |
| 文言 | 移動: MSG-I-009 と「元に戻す」。元に戻した: MSG-I-010（そこから 8 秒）。失敗: MSG-E-007 |
| 読み上げ | 成功は `role="status"`、失敗は `role="alert"` |

## 4. SCR-02 商品の追加・編集のモーダル

### 4.1 入力欄

| 入力欄 | 種類 | 初期値（追加） | 備考 |

| 商品名 | 文字 | 空 | 必須。開いたときに入力位置を置く |

| カテゴリー | 選択 | 未設定 | 「未設定」と定義のカテゴリー（定義の並び順）。編集する商品のカテゴリーが定義にない場合は「名前（定義にない）」も加え、それを選んだ状態にする。定義に誤りがある場合は変更できなくし、MSG-I-007 を表示する（#10） |
| 発売月 | 年月 | 当月 | 必須 |
| ステータス | 選択 | 検討中 | 検討中・予約済・購入済・未購入 |
| キャンセル可 | チェック | なし | |
| 金額（税込） | 数値 | 空 | 0〜9,999,999 円 |
| 送料（税込） | 数値 | 空 | 0〜9,999,999 円 |
| 手数料 | 数値 | 空 | 0〜9,999,999 円（#26） |
| 交通費（見込） | 数値 | 空 | 0〜9,999,999 円（#26） |
| その他費用 | 数値 | 空 | 0〜9,999,999 円。表記はカテゴリーの「その他費用」の名前（例: ドリンク代。BR-26）（#26・#27） |
| 開催日時・終了日時 | 日時（日本時間・分まで） | 空 | 2 つで 1 組。UTC にして送る。終了日時が開催日時より前なら MSG-V-029 を終了日時の下に表示して送らない（PR #30） |
| 場所 | 文字 | 空 | 100 文字以内（#26） |
| 受注期限 | 日付 | 空 | |
| 購入先の URL | URL | 空 | http・https のみ。画像の欄のすぐ上に置く。貼り付けたとき（すぐ）と、入力して欄を離れたときに、カード画像のプレビューを取りに行く（#51。BR-36。下記） |
| 画像 | ファイルの選択 | なし | 画像のファイルだけを選べる。選んだら長い辺を 800px 以内に縮めてプレビュー（「選んだ画像」）を表示する。読めないファイルは MSG-E-015 を欄の下に表示する。編集では今の画像（「今の画像」）を表示する。選んだ画像か今の画像があるときは「画像を消す」ボタンを表示する。縮めている間は保存できない（#41）。ファイルの選択の下に貼り付け欄（「画像の貼り付け欄」）を置き、空のときは案内 MSG-I-015 を表示する（#45・#47。下記）。ラベルの下に注釈 MSG-I-016 を表示する。購入先の URL のカード画像のプレビュー（「購入先のページの画像」。canvas）・取得中 MSG-I-017・取れなかった MSG-I-018 を、選んだ画像・今の画像の代わりに表示する（#51。下記） |
| 備考 | 複数行の文字 | 空 | 1,000 文字以内（#18） |

カテゴリーの入力欄は #10、メーカー・備考の入力欄は #18、場所・費用は #26、開催日時・終了日時は PR #30 のレビュー、画像は #41 で追加する。

メーカー・キャンセル可・送料・手数料・交通費（見込）・その他費用・開催日時と終了日時・場所・受注期限は、カテゴリーごとに出し入れする（#27。BR-24）。選んでいるカテゴリーで有効な項目と、開いた時点で値が保存されている項目だけを表示し、カテゴリーを選び直したらすぐに表示を変える。カテゴリー未設定・定義にないカテゴリーではメーカー・キャンセル可・送料・受注期限を表示する。定義に誤りがある場合はすべて表示する。表示していない項目は未入力として送る。

横幅 600px 以下では入力欄を 1 列に並べる。ただし金額と送料、手数料と交通費（見込）は短いため横に並べたままにする（#16・#26）。

### 4.2 操作

| 操作 | 結果 |
| --- | --- |
| 保存 | 入力を検証し、誤りがあれば入力欄の下に文言を表示して送信しない。正しければ保存し、モーダルを閉じて一覧を読み込み直す。購入先の URL を入れた・変えた（またはカード画像がない）場合、サーバーがカード画像を取りに行く。モーダルはそれを待たずに閉じ、一覧は取り終わるまで 2 秒ごと（30 秒まで）に読み直して、取れたら画像を表示する（#42） |
| 保存ボタンの横の ▾（追加のみ） | 保存の方法のメニュー（「保存」「保存して続けて追加」。今の方法に ✓）を開く。選ぶと保存ボタンの表示がその方法になり、モーダルを開いている間保つ（選んだだけでは保存しない）。Esc キー・メニューの外を押すとメニューだけを閉じる。上下の矢印キーで項目を移る（#16） |
| 保存して続けて追加（保存の方法で選んだ場合） | 保存までは「保存」と同じ。保存したらモーダルを開いたまま、MSG-I-006 を表示し、一覧を読み込み直す。商品名・金額・送料・URL・メーカー・備考・場所・手数料・交通費（見込）・その他費用・開催日時・終了日時を空に戻し、発売月・ステータス・キャンセル可・受注期限・カテゴリーは残して、商品名に入力位置を置く（#16・#26）。画像の欄も空に戻す。画像を保存できなかった場合は、MSG-I-006 の代わりに MSG-E-017 を表示する（#41） |
| キャンセル・Esc キー | 保存せずに閉じる（選んだ画像・「画像を消す」も反映しない） |
| 画像を消す | 選んだ画像を外す。編集で今の画像（アップロードした画像）がある場合は、保存したときに今の画像を消す（#41）。外した後は、購入先の URL のカード画像のプレビューがあれば表示する。今の画像がカード画像の場合・カード画像のプレビューだけの場合はボタンを出さない（選んだ画像を外すと今のカード画像の表示に戻る）（#51） |
| 購入先の URL の貼り付け・入力して欄を離れる | サーバーにカード画像を取ってもらい（保存はしない）、画像の欄に表示する（BR-36）。取りに行っている間は MSG-I-017、取れなかった場合は MSG-I-018 を表示する（どちらも保存はできる）。同じ URL では取り直さない。空・形の誤り・保存済みの URL のままでは取りに行かず、プレビューを消す。選んだ画像・今のアップロードした画像があれば、そちらを表示したままにする。今の画像がカード画像なら、新しい URL の表示に置き換える。「保存して続けて追加」の後はプレビューを消す（#51） |
| 画像の貼り付け（Ctrl/⌘+V・長押しの「ペースト」） | クリップボードの最初の画像を、ファイルを選んだときと同じく縮めてプレビューにする（選んであったファイルは外す）。モーダルのどこで貼り付けても受け取り、文字の欄に入力位置があっても画像があれば画像として受け取る（文字は入れない）。画像がなければ今までどおりの動作にする。貼り付け欄では文字を入れず、画像がなければ MSG-E-018 を欄の下に表示する。読めない画像は MSG-E-015。貼り付け欄は文字を入力できず、触れてもキーボードを出さない（`inputmode="none"`）。スマートフォン・タッチ操作の端末では、入力欄と同じく文字を 16px にし、タップで画面が拡大されないようにする（#47）。`http://` で配信しているため、ボタンでクリップボードを読む方式（HTTPS が必要）は使わない（#45） |
| 削除（編集のみ） | SCR-03 を開く |
| リストに戻す（アーカイブの商品の編集のみ） | SCR-05 を開く |

保存に失敗した場合は、モーダルの上部にエラーを表示し、入力は残す。サーバーが入力の誤りを返した場合は、該当する入力欄の下に表示する。

画像は、保存のときに商品を保存してから送る・消す（商品を保存できなければ送らない。BR-32）。画像だけを保存できなかった場合は、商品は保存したままモーダルを閉じ、一覧（SCR-01）・アーカイブ（SCR-04）の画面の下端の知らせ（3.7）に MSG-E-016 を `role="status"` で表示する（#41）。

アーカイブされた商品（SCR-04 から開いた場合）は、発売月を変更できない（入力欄を無効にし、下に「発売月は「リストに戻す」で変更します。」と表示する）。発売月は SCR-05 で変える（自動遷移の前のステータスに戻す手順を通すため）。

│   ▼ 2026/10 1個（合計 22,800円）              │  ← 新しい月から

- ツールバーにカテゴリーの絞り込み（3.5）を置く。SCR-01 と同じ選択を使い、ここで変えた選択は SCR-01 にも反映する（#10）
- 見出しの集計は実績のため「1個（合計 22,800円）」と表記する（「見込」を付けない）。集計の対象（未購入を除く）と、同じ月の中の並び順は SCR-01 と同じ

- 横幅 600px 以下では、SCR-01 と同じリスト形式（3.3）で表示する（#15）
- カードを押すと SCR-02 を「編集」で開く（発売月は変更できず、「リストに戻す」ボタンを表示する）
- 年・月の見出しを押すと折りたたみ・展開する

## 7. SCR-05 リストに戻す

- 題名「リストに戻す」、本文に商品名、「新しい発売月」の入力欄（既定は当月）と「ステータスはアーカイブ時に自動で変わる前に戻ります（手で変えたステータスはそのまま）。」
- 「戻す」で、新しい発売月が当月以降かを確かめ、当月より前なら「発売月は当月（2026/11）以降を指定してください。」を入力欄の下に表示して送信しない。正しければリストに戻し、モーダルを閉じて一覧を読み込み直す

- 「キャンセル」・Esc キーで閉じる

## 8. SCR-06 延期の確認

- 題名「発売月を過ぎた予約商品の確認」、本文に MSG-I-004
- 確認を待っている商品ごとに、商品名、「発売月 2026/10 ・ 予約済 → 購入済」と、「届いた」「延期された」「買わなかった」の選択肢を表示する
  - 「延期された」を選ぶと「新しい発売月」の入力欄（既定は当月）を表示する
- 「回答を保存」で、回答した商品だけを送る（1 件も回答していない間は押せない）。すべて送れたらモーダルを閉じ、表示中の一覧を読み込み直す
  - 「延期された」の新しい発売月が当月より前なら、その商品の下に「発売月は当月（2026/11）以降を指定してください。」を表示して送信しない
  - 送信に失敗した場合は MSG-E-005 を表示する。送れた商品は選択肢を無効にし、やり直しでは送らない
- 「あとで」・Esc キーで送らずに閉じる。開き直すまで再表示しない（回答しなかった商品は次に開いたときに再表示する）

## 9. SCR-07 カテゴリーの管理（#10）

```
┌ カテゴリーの管理 ───────────────────────────┐
│ [スケールフィギュア    ] 9件 [名前を変更][削除] │
│ [可動フィギュア        ] 6件 [名前を変更][削除][入力する項目] │
│   MSG-I-014                                  │  ← 「入力する項目」を開いたとき（#27）
│   ☑送料 ☑メーカー ☑受注期限 ☑キャンセル可 ☐場所      │
│   ☐開催日時・終了日時 ☐手数料 ☐交通費（見込） ☐その他費用 │
│   [その他費用          ] [費用の名前を変更]          │
│   「可動フィギュア」は 6 件の商品が使っています。… │  ← 使われているカテゴリーの削除の確認
│   移す先[スケールフィギュア▾] [移して削除]        │
│   [カテゴリー未設定にして削除] [やめる]           │
│ [新しいカテゴリー      ] [追加]                 │
│ MSG-I-011                                    │
│ ── 定義にないカテゴリー ──                     │  ← 定義にないカテゴリーの商品があるときだけ
│ MSG-I-012                                    │
│ 「プライズ」 3件                               │
│ [定義に追加する][別のカテゴリーに移す][カテゴリー未設定にする] │
│                                    [閉じる] │
└──────────────────────────────────────────────┘
```

- 開いたときにカテゴリーの定義と商品（アーカイブを含む）を読み込み、定義の並び順でカテゴリーと、使っている商品の数を表示する
- 追加・改名・削除・定義にないカテゴリーの選択は、操作ごとにすぐサーバーに送り、定義のファイルに保存する（まとめて保存するボタンはない）。送った後は、成否にかかわらず定義と商品を読み込み直す
- 追加: 「新しいカテゴリー」に名前を入れて「追加」か Enter キー。定義の末尾に加え、入力欄を空にする。名前が空・50 文字を超える場合は MSG-V-016・MSG-V-017 を表示して送らない
- 改名: 名前の入力欄を書き換えて「名前を変更」か Enter キー（名前を変えるまで押せない）。そのカテゴリーの商品も新しい名前になる
- 削除: 商品が使っていなければ確認せずに削除する。使っていれば行の下に MSG-C-003 と、「移す先」（ほかの定義のカテゴリー。既定は並び順の最初）・「移して削除」・「カテゴリー未設定にして削除」・「やめる」を表示する。ほかの定義のカテゴリーがなければ「移す先」と「移して削除」は出さない。アーカイブの商品も移す
- 定義にないカテゴリー（商品に付いているが定義にない）があれば、見出し「定義にないカテゴリー」と MSG-I-012 の下に、名前（商品に最後に保存した名前）・商品の数と、次の選択肢を表示する。アプリを開いたときに自動では表示しない
  - 「定義に追加する」: 同じ ID と、その名前で定義の末尾に加える。定義に同じ名前があれば MSG-V-018 を表示する
  - 「別のカテゴリーに移す」: 「移す先」（定義のカテゴリー）・「移す」・「やめる」を表示する。定義にカテゴリーがなければ押せない
  - 「カテゴリー未設定にする」: その商品をすべてカテゴリー未設定にする
- サーバーが拒否した場合（名前の重複 MSG-V-018、定義から消えていた MSG-V-015 など）はサーバーの文言を、それ以外の失敗は MSG-E-008 をモーダルの上部に表示する
- 入力する項目（#27）: 定義のカテゴリーの行の「入力する項目」（開閉。閉じた状態で開く）を押すと、行の下に MSG-I-014、出し入れする項目のチェックボックス（送料・メーカー・受注期限・キャンセル可・場所・開催日時・終了日時・手数料・交通費（見込）・その他費用）と「その他費用の名前」の欄・「費用の名前を変更」を表示する
  - チェックは押すたびに、変えた項目だけを送る（BR-27）
  - 名前は「費用の名前を変更」か Enter キーで送る（名前を変えるまで押せない）。空にして送ると「その他費用」に戻す。20 文字を超える場合は MSG-V-028 を表示して送らない
  - 定義にないカテゴリーの行には出さない
- 定義のファイルに誤りがある場合は、モーダルの上部に MSG-E-006 を表示し、カテゴリーの一覧・追加の欄を出さない
- 「閉じる」・Esc キーで閉じる。変更した場合は、表示中の一覧（SCR-01・SCR-04）を読み込み直す（絞り込みとモーダルのカテゴリーにも反映する）
