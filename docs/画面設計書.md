# 画面設計書

Waders の画面の構成・レイアウト・操作と、画面に表示する文言を定める。見た目の参考は [mock/index.html](mock/index.html)（モック）。実装（`src/client/`）と常に一致させる。

## 1. 画面の一覧

| 番号 | 画面 | 内容 | issue |
| --- | --- | --- | --- |
| SCR-01 | 商品の一覧 | 発売月ごとのリスト。追加・編集のモーダルを開く | #8 |
| SCR-02 | 商品の追加・編集のモーダル | 商品の入力と保存・削除 | #8 |
| SCR-03 | 削除の確認 | 削除してよいかの確認 | #8 |
| SCR-04 | アーカイブ | 発売月が当月より前の商品の一覧。編集とリストに戻すを開く | #9 |
| SCR-05 | リストに戻す | アーカイブされた商品を、新しい発売月でリストに戻す | #9 |
| SCR-06 | 延期の確認 | 自動で購入済になった予約商品が届いたかの確認 | #9 |

今後の予定: カテゴリーの管理（#10）、ログイン（#11）。

ステータスの自動遷移とアーカイブの規則は [機能設計書](機能設計書.md) に定める。

## 2. 共通

- PC・スマートフォン・タブレットのブラウザで、すべての機能を使える。横幅 600px 以下ではスマートフォン向けの配置にする
  - 横幅 600px 以下とタッチ操作の端末では、入力欄の文字を 16px にする（iOS Safari がタップ時に画面を拡大しないようにするため。指での拡大は禁止しない）（#16）
  - 年月・日付の入力欄は標準の見た目を外し、入力欄の幅に収める（iOS Safari ではみ出すため）（#16）
- モーダルを開いている間は、背景のページをスクロールさせない（#16）
- 画面の最上部にアプリ名「Waders」と、「リスト」（SCR-01）・「アーカイブ」（SCR-04）のタブのヘッダーを固定表示する。開いたときは「リスト」を表示する
- 開いたときに延期の確認を待っている商品があれば、SCR-06 を表示する
- 日付・月は日本時間で判定する
- スタイルは CSS のクラスで指定する（CSP によりインラインのスタイルは使えない）

## 3. SCR-01 商品の一覧

### 3.1 構成

```
┌ Waders [リスト|アーカイブ] ──────────────────┐  ← ヘッダー
│ [暦年|年度]                              (＋) │  ← ツールバー
│ ▼ 2026年 5個（合計 100,680円見込）            │  ← 年の見出し
│ ──────────────────────────────────────────── │
│   ▼ 2026/11 3個（合計 77,580円見込）      (＋) │  ← 月の見出し（右端に追加ボタン）
│     [カード][カード][カード][カード]          │  ← 列数は横幅に合わせる
│   ▼ 2027/01 0個（合計 0円見込）           (＋) │
│     商品はありません                          │
└──────────────────────────────────────────────┘
```

### 3.2 表示

- 年・月のグループで表示し、見出しを押すと折りたたみ・展開する（開くたびにすべて展開した状態にする）
  - 年のまとめ方は「暦年」（1月〜12月、表記「2026年」）と「年度」（4月〜翌3月、開始年で表記「FY26」）を切り替える。切り替えはブラウザに保存し、次に開いたときも使う
  - 月の表記は「2026/11」
- 見出しに、個数と合計金額の見込みを「3個（合計 44,000円見込）」と表示する
  - 未購入の商品は含めない
  - 合計は金額と送料の合計。金額が未入力の商品は個数だけに含める
- 発売月が当月以降の商品だけを表示する。当月より前の商品は SCR-04 に表示する（#9）
- 表示する月は、当月から登録されている商品の最も遅い発売月まで。0 件の月も表示し「商品はありません」と表示する
- 同じ月の中は、購入済 → 予約済 → 予約済（キャンセル可）→ 検討中 → 未購入の順。同じステータスの中は登録順
- カードの列数は横幅に合わせる（PC はカードの幅 180px 以上、スマートフォンは 150px 以上で並べる）

### 3.3 商品のカード

| 部分 | 内容 |
| --- | --- |
| 画像 | 共通のアイコン（画像の登録は今後の issue） |
| ステータス | 画像の左上に表示（検討中・予約済・予約済（キャンセル可）・購入済・未購入） |
| メーカー | 入力がある場合だけ、商品名の上に小さく薄い文字で 1 行（長い場合は省略）（#18） |
| 商品名 | 3 行まで。検討中で受注期限まで 0〜7 日の場合は先頭に「⚠️ 」を付ける |
| 金額・送料 | 「24,200円 送料 800円」。送料が未入力・0 円は「送料無料」。金額が未入力は「金額未入力」（送料は表示しない） |
| 備考の印 | 備考がある場合だけ、金額の行の右端に 📝（読み上げは「備考あり」）。本文は表示しない（#18） |
| 受注期限 | 検討中の場合だけ「受注期限 11/20」。⚠️ の対象は赤字 |
| 購入先 | URL のドメインをリンクとして表示し、新しいタブで開く。カードの下端にそろえる（#16） |

ステータスの色（モックの配色）:

| ステータス | 背景 | 左の線 | 備考 |
| --- | --- | --- | --- |
| 検討中 | 黄 | 黄 | |
| 予約済 | 白 | グレー | |
| 予約済（キャンセル可） | 青 | 青 | |
| 購入済 | グレー | グレー | 文字を薄くする |
| 未購入 | 白 | 赤 | 枠を赤い破線にし、画像を薄くする（購入済のグレーと見分けるため。取り消し線は付けない） |

### 3.4 操作

| 操作 | 結果 |
| --- | --- |
| ＋ボタン | SCR-02 を「追加」で開く（発売月は当月） |
| 月の見出しの＋ボタン | SCR-02 を「追加」で開く（発売月はその月）。月を折りたたんでいても押せる。SCR-04 には置かない（#16） |
| カードを押す | SCR-02 を「編集」で開く |
| 購入先のリンクを押す | 購入先のページを新しいタブで開く（編集は開かない） |

## 4. SCR-02 商品の追加・編集のモーダル

### 4.1 入力欄

| 入力欄 | 種類 | 初期値（追加） | 備考 |
| --- | --- | --- | --- |
| 商品名 | 文字 | 空 | 必須。開いたときに入力位置を置く |
| メーカー | 文字 | 空 | 100 文字以内。登録済みの商品（アーカイブを含む）のメーカーを、重複なく日本語の順に入力の候補として出す（#18） |
| 発売月 | 年月 | 当月 | 必須 |
| ステータス | 選択 | 検討中 | 検討中・予約済・購入済・未購入 |
| キャンセル可 | チェック | なし | |
| 金額（税込） | 数値 | 空 | 0〜9,999,999 円 |
| 送料（税込） | 数値 | 空 | 0〜9,999,999 円 |
| 受注期限 | 日付 | 空 | |
| 購入先の URL | URL | 空 | http・https のみ |
| 備考 | 複数行の文字 | 空 | 1,000 文字以内（#18） |

カテゴリーの入力欄は #10、メーカー・備考の入力欄は #18 で追加する。

横幅 600px 以下では入力欄を 1 列に並べる。ただし金額と送料は短いため横に並べたままにする（#16）。

### 4.2 操作

| 操作 | 結果 |
| --- | --- |
| 保存 | 入力を検証し、誤りがあれば入力欄の下に文言を表示して送信しない。正しければ保存し、モーダルを閉じて一覧を読み込み直す |
| 保存ボタンの横の ▾（追加のみ） | 保存の方法のメニュー（「保存」「保存して続けて追加」。今の方法に ✓）を開く。選ぶと保存ボタンの表示がその方法になり、モーダルを開いている間保つ（選んだだけでは保存しない）。Esc キー・メニューの外を押すとメニューだけを閉じる。上下の矢印キーで項目を移る（#16） |
| 保存して続けて追加（保存の方法で選んだ場合） | 保存までは「保存」と同じ。保存したらモーダルを開いたまま、MSG-I-006 を表示し、一覧を読み込み直す。商品名・金額・送料・URL・メーカー・備考を空に戻し、発売月・ステータス・キャンセル可・受注期限は残して、商品名に入力位置を置く（#16） |
| キャンセル・Esc キー | 保存せずに閉じる |
| 削除（編集のみ） | SCR-03 を開く |
| リストに戻す（アーカイブの商品の編集のみ） | SCR-05 を開く |

保存に失敗した場合は、モーダルの上部にエラーを表示し、入力は残す。サーバーが入力の誤りを返した場合は、該当する入力欄の下に表示する。

アーカイブされた商品（SCR-04 から開いた場合）は、発売月を変更できない（入力欄を無効にし、下に「発売月は「リストに戻す」で変更します。」と表示する）。発売月は SCR-05 で変える（自動遷移の前のステータスに戻す手順を通すため）。

## 5. SCR-03 削除の確認

- 題名「商品を削除しますか？」、本文に商品名と「削除した商品は元に戻せません。」
- 「削除する」で削除し、モーダルを閉じて一覧を読み込み直す。「削除しない」で確認だけを閉じる

## 6. SCR-04 アーカイブ

```
┌ Waders [リスト|アーカイブ] ──────────────────┐
│ ▼ 2026年 2個（合計 41,300円）                 │  ← 年の見出し（実績）
│   ▼ 2026/10 1個（合計 22,800円）              │  ← 新しい月から
│     [カード][カード]                          │
│   ▼ 2026/09 1個（合計 18,500円）              │
│     [カード]                                  │
└──────────────────────────────────────────────┘
```

- 発売月が当月（日本時間）より前の商品を表示する。月は新しい順で、商品のある月だけを表示する
- 年のまとめ方は SCR-01 で選んだもの（暦年・年度）を使う。SCR-04 では切り替えない
- 見出しの集計は実績のため「1個（合計 22,800円）」と表記する（「見込」を付けない）。集計の対象（未購入を除く）と、同じ月の中の並び順は SCR-01 と同じ
- 商品がない場合は「アーカイブされた商品はありません」と表示する
- カードを押すと SCR-02 を「編集」で開く（発売月は変更できず、「リストに戻す」ボタンを表示する）
- 年・月の見出しを押すと折りたたみ・展開する

## 7. SCR-05 リストに戻す

- 題名「リストに戻す」、本文に商品名、「新しい発売月」の入力欄（既定は当月）と「ステータスはアーカイブ時に自動で変わる前に戻ります（手で変えたステータスはそのまま）。」
- 「戻す」で、新しい発売月が当月以降かを確かめ、当月より前なら「発売月は当月（2026/11）以降を指定してください。」を入力欄の下に表示して送信しない。正しければリストに戻し、モーダルを閉じて一覧を読み込み直す
- サーバーが拒否した場合（アーカイブされていないなど）はサーバーの文言を、それ以外の失敗は MSG-E-004 をモーダルの上部に表示する
- 「キャンセル」・Esc キーで閉じる

## 8. SCR-06 延期の確認

- 題名「発売月を過ぎた予約商品の確認」、本文に MSG-I-004
- 確認を待っている商品ごとに、商品名、「発売月 2026/10 ・ 予約済 → 購入済」と、「届いた」「延期された」「買わなかった」の選択肢を表示する
  - 「延期された」を選ぶと「新しい発売月」の入力欄（既定は当月）を表示する
- 「回答を保存」で、回答した商品だけを送る（1 件も回答していない間は押せない）。すべて送れたらモーダルを閉じ、表示中の一覧を読み込み直す
  - 「延期された」の新しい発売月が当月より前なら、その商品の下に「発売月は当月（2026/11）以降を指定してください。」を表示して送信しない
  - 送信に失敗した場合は MSG-E-005 を表示する。送れた商品は選択肢を無効にし、やり直しでは送らない
- 「あとで」・Esc キーで送らずに閉じる。開き直すまで再表示しない（回答しなかった商品は次に開いたときに再表示する）
